# 信息数显流程间隔配置说明

## 快速开始

1. 编辑 `config/intervals.json`，调整间隔值
2. 运行 `python tools/apply_intervals.py` 应用配置
3. 重启程序

## 配置文件结构

```json
{
  "基础间隔_ms": 100,
  "每步叠加间隔_ms": {
    "步骤0_初始缓冲": 0,
    "步骤2_ESC到菜单弹出": 100,
    "步骤4_点击到响应": 0,
    "步骤6_第二次ESC到UI切换": 50
  }
}
```

### 基础间隔
所有 wait 步骤的默认等待时间。实际等待 = 基础间隔 + 该步骤的叠加间隔。

### 每步叠加间隔
在基础间隔之上，为特定关键步骤额外增加的等待时间。

## 流程结构

完整数显流程 = **显示UI(7步)** → **截图** → **隐藏UI(7步)**

每次 UI 切换的 7 个步骤：

| 步骤 | 动作 | 说明 | 可调叠加间隔 |
|------|------|------|-------------|
| 0 | wait | 初始缓冲（给游戏响应时间） | ✅ |
| 1 | press_key | 按 ESC 唤出游戏菜单 | - |
| 2 | wait | 等待菜单完全弹出（**关键步骤**） | ✅ |
| 3 | click | 点击"无UI"按钮 | - |
| 4 | wait | 等待点击响应 | ✅ |
| 5 | press_key | 按 ESC 关闭菜单 | - |
| 6 | wait | 等待菜单关闭 + UI 切换完成 | ✅ |

## 调优指南

### 问题：第一次点击不生效（菜单没弹出来就点了）
**解决**：增大 `步骤2_ESC到菜单弹出` 的叠加间隔
- 从 100 开始，逐步加到 200、300
- 这是最常见的问题，游戏菜单弹出需要时间

### 问题：流程太慢
**解决**：逐步减小 `基础间隔_ms`
- 从 100 降到 50，再降到 30 试
- 同时减小各步叠加间隔
- 找到最小稳定值

### 问题：点击后 UI 没切换
**解决**：增大 `步骤6_第二次ESC到UI切换` 的叠加间隔
- 从 50 加到 100、150

### 问题：不同机器兼容性差
**解决**：
- 基础间隔设为机器最小值（如 50ms）
- 关键步骤（步骤2、步骤6）加叠加间隔
- 快机器叠加间隔小，慢机器叠加间隔大

## 固定间隔（不可通过此文件配置）

以下间隔在代码中固定，如需修改请告知：

| 间隔 | 默认值 | 说明 |
|------|--------|------|
| 按键按下时间 | 50ms | press_key 时按键按住的时间 |
| 点击后等待 | 30ms | click 后等待系统处理点击事件 |
| 截图前等待 | 10ms | 显示UI后、截图前的短暂等待 |

## 注意事项

- 修改 `intervals.json` 后**必须运行** `python tools/apply_intervals.py` 才能生效
- 应用后**必须重启程序**
- 间隔单位是毫秒（ms）
- 叠加间隔可以是负数（减少该步骤的等待时间），但实际等待不会低于 10ms
- 配置文件中的 `_说明`、`_流程结构`、`_调优建议` 字段是注释，不会被应用
