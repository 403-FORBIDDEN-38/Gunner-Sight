# 截图流程（信息数显）配置说明

## 配置文件位置
`config/config.json` → `profiles` → 选中的 profile → `toggle_steps` 数组

## 流程结构
数显流程 = 显示UI(ESC+点击) → 截图 → 隐藏UI(ESC+点击)

每次 UI 切换由 7 个步骤组成：

| 步骤 | 类型 | 说明 |
|------|------|------|
| 0 | wait | 初始缓冲（给游戏响应时间） |
| 1 | press_key | 按 ESC 唤出游戏菜单 |
| 2 | wait | 等待菜单完全弹出（关键步骤，建议多等） |
| 3 | click | 点击"无UI"按钮（坐标由 global_ui_button 配置） |
| 4 | wait | 等待点击响应 |
| 5 | press_key | 按 ESC 关闭菜单 |
| 6 | wait | 等待菜单关闭 + UI 切换完成 |

## 可调参数

### 方式一：基础间隔（推荐）
在 profile 中设置 `toggle_ui_step_interval`（毫秒），所有 wait 步骤统一使用此间隔。

```json
"toggle_ui_step_interval": 100
```

### 方式二：每步单独间隔
在 `toggle_steps` 数组中，每个 wait 步骤的 `ms` 字段单独设置。

```json
"toggle_steps": [
    {"action": "wait", "ms": 50},
    {"action": "press_key", "key": "esc"},
    {"action": "wait", "ms": 200},
    {"action": "click"},
    {"action": "wait", "ms": 50},
    {"action": "press_key", "key": "esc"},
    {"action": "wait", "ms": 150}
]
```

### 方式三：基础间隔 + 每步偏移（最灵活）
设置 `toggle_ui_step_interval` 作为基础间隔，然后在每个 wait 步骤中设置 `extra_ms` 作为额外偏移。

实际等待 = 基础间隔 + extra_ms

```json
"toggle_ui_step_interval": 100,
"toggle_steps": [
    {"action": "wait", "ms": 50, "extra_ms": 0},
    {"action": "press_key", "key": "esc"},
    {"action": "wait", "ms": 200, "extra_ms": 100},
    {"action": "click"},
    {"action": "wait", "ms": 50, "extra_ms": 0},
    {"action": "press_key", "key": "esc"},
    {"action": "wait", "ms": 150, "extra_ms": 50}
]
```

上例中：步骤0=100ms, 步骤2=200ms, 步骤4=100ms, 步骤6=150ms

## 调优建议

1. **第一次点击不生效**：增大步骤2（ESC→菜单弹出）的等待时间，建议 200-300ms
2. **流程太慢**：逐步减小各 wait 步骤，从 50ms 开始试，找到最小稳定值
3. **不同机器兼容**：用方式三（基础间隔+偏移），基础间隔设为机器最小值，关键步骤加偏移
4. **按钮坐标**：在 profile 外的 `global_ui_button` 配置，格式 `{"x": 1225, "y": 1050}`

## 注意事项
- 修改配置后需要重启程序或切换 profile 才能生效
- 间隔单位是毫秒（ms）
- press_key 的按下时间固定为 50ms（不可配置）
- click 的点击后等待固定为 30ms（不可配置）
