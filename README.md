# GunnerSight

Squad 载具炮手辅助工具。炮镜分划叠加、信息数显、地图比例尺测距、炮塔俯仰角显示、建队宏，全部本地运行，不读内存不注入。

---

## 它能做什么

**炮镜叠加** — 透明置顶穿透层，按载具→弹种→倍率自动切换炮镜图片，支持缩放/偏移/透明度（全局与载具级二选一）、一键反色。

**信息数显** — 无UI模式下一键恢复UI→截图测距区域→恢复无UI，把测距数值贴回屏幕，同时保有UI的信息和无UI的视野。双截取区域，执行间隙可调。

**地图比例尺测距** — 以游戏地图自带的比例尺为基准标定像素/米换算率，之后任意两点在地图上的像素距离即得实际米数。四档比例尺（33/100/300/900m）循环切换，支持快速测距（沿用上一次点1）。

**角度仪** — 基于 RawInput 鼠标增量实时推算炮塔俯仰角。每武器站独立校准曲线（3–11点），多方案可切换。微调热键点按/短长按/长长按三档，归零与暂离齐备。

**建队宏** — 自动化 Squad 控制台建队流程，循环间隔可调，支持锁队。

**全局热键** — 键盘+鼠标全局钩子，每功能双键槽位，支持按下/松开触发、Hold to Aim。ESC 清除绑定。

信息数显、标定测距、角度仪、建队宏均为可选模块，关闭即零消耗。

## 快速开始

**系统要求**：Windows 10/11，游戏设为窗口化或无边框窗口（全屏独占下叠加层无法显示）。

**运行**：右键 `GunnerSight.exe` → 以管理员身份运行（信息数显的 BlockInput 需要管理员权限，非管理员可运行但该功能受限）。

**从源码**：
```bash
pip install PyQt5 mss keyboard pillow
python main.py
```

**上手五步**：载具配置页建载具/弹种/倍率 → 资源库导入透明底PNG炮镜 → 载具配置页给各倍率绑炮镜 → 热键页绑键 → 进游戏按显示热键。

详见 [USER_GUIDE.md](USER_GUIDE.md)。

## 配置与数据

- `config/config.json` — 全部用户配置（载具、弹种、倍率、热键、各模块参数），退出自动保存，旧版本自动迁移
- `resources/` — 炮镜图片、字体、吉祥物素材
- 备份 = 复制这两个目录

## 开发

| 项 | 内容 |
|---|---|
| 语言 | Python 3 |
| GUI | PyQt5 |
| 截图 | mss |
| 全局输入 | keyboard + 自定义低级鼠标钩子 + RawInput |
| 系统接口 | ctypes / Win32 API |
| 测试 | pytest（`tests/`，79例） |
| 打包 | PyInstaller onedir，config/resources 外置 exe 同级 |
| 版本号 | 唯一来源 `gui/tabs/info_tab.py` 的 `APP_VERSION` |

```
core/        逻辑层（配置、状态机、热键、overlay、各模块引擎）
gui/         UI层（主窗口、通用控件、热键绑定组件）
gui/tabs/    9个页签
resources/   静态资源
tests/       测试
docs/        文档与工作流
```
