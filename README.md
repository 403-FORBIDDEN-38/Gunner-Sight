# GUNNER SIGHT

为 **Squad** 提供屏幕准星叠加的桌面工具。透明置顶窗口 + 图片叠加 + 全局热键，**不读取游戏内存、不修改游戏文件、不注入进程**。

## 特性

- **77 套载具分划，开箱即用**：出厂配置文件随包发布，启动即有准星，不需要先配置
- **滚轮预选弹种**：游戏内滚动滚轮选弹种，左键确认，无需离开鼠标
- **多分辨率自适应**：1K / 2K / 4K，按挡位等比缩放，圆形不变形
- **四个可选模块**：角度仪、标定测距、放大镜、建队宏，默认关闭，关闭时零开销
- **全局热键**：支持单键与组合键，游戏在前台时同样生效
- **完全离线**：无网络请求，无遥测，无账号

## 快速开始

### 使用发布版

1. 解压到任意目录（不要放在需要管理员权限的路径下）
2. 运行 `GUNNER SIGHT.exe`
3. 屏幕上出现准星即表示启动成功
4. 游戏内按 `Q` 或鼠标右键循环倍率，按 `F1` 显示/隐藏准星

出厂已配置 77 套载具和一组默认热键，**不需要先配置**。完整操作说明见下方文档。

### 从源码运行

```bash
uv sync
py main.py
```

两种方式功能完全相同，都不需要管理员权限。

## 构建

```bash
tools/build.bat
```

脚本自动选择解释器：有 `uv` 时走 `uv run`（自动安装构建依赖），否则用系统 `py` 启动器（需提前 `py -m pip install nuitka zstandard`；构建依赖也可用 `uv sync --extra build` 预装）。

产出 `dist/main.dist/GUNNER SIGHT.exe`，Nuitka onedir 模式。首次构建约 60 秒，之后利用编译缓存会快得多。

**注意**：首次构建会从互联网下载 MinGW C 编译器（约 100MB），离线或网络受限环境无法完成构建。产物仅 x64（Windows on ARM 靠模拟运行，无保证）。

## 项目结构

```
GunnerSight/
├── main.py                 启动与退出编排、跨模块信号接线
├── core/                   业务层：配置、状态机、叠加层、钩子、各模块引擎
├── gui/                    界面层：主窗口、通用控件、10 个页面
├── resources/              分划图片、图标、字体、启动横幅

├── tests/                  回归测试
├── docs/                   项目文档（交接、变更日志、审查报告）
└── tools/                  开发辅助脚本与打包脚本
```

发布版目录结构：

```
GUNNER SIGHT.exe
config/
├── config.json        用户配置（明文，可手动编辑）
└── bbox_cache.json    偏移缓存（自动生成，可安全删除）
resources/             分划图片资源
```

## 已知限制

- **鼠标焦点在 Windows 桌面时，滚轮切弹种无效**：系统级鼠标钩子在前台为桌面时收不到滚轮事件。切到任意其他窗口立即恢复。非 Bug，无法在程序层解决。
- **筛选结果为空时，载具列表显示为无选中**：详情区仍显示当前载具。设计取舍。
- **无弹种的载具，倍率列表显示未绑定图片**：先配置弹种即可。
