# GunnerSight Overlay

Squad 游戏载具炮手辅助工具。在屏幕上叠加自定义炮镜分划，随载具/弹种/倍率自动切换，并提供信息数显、角度仪、建队宏等实战功能。

本地运行，不读取游戏内存，不注入进程，不修改游戏文件。永久免费。

---

## 核心特性

- **自定义准星叠加** — 透明置顶、鼠标穿透，按载具→弹种→倍率三级自动切换炮镜图片，支持缩放、偏移、一键反色
- **全局热键** — 键盘+鼠标全局钩子，每功能双键槽位，支持按下/松开触发，Hold to Aim（按住显示、松开隐藏）
- **多载具配置** — 每载具独立弹种、倍率、准星绑定，标签筛选，弹种热键按载具维度独立（不同载具可共用键位）
- **信息数显** — 无UI模式下自动恢复UI→截图测距区域→恢复无UI→叠加显示结果，双截取区域，替代原炮镜视野
- **角度仪** — 基于鼠标增量实时显示炮塔俯仰角，全局/载具两级校准，归零/暂离/重置
- **建队宏** — 自动化 Squad 控制台建队流程，循环间隔可调，支持锁队
- **无UI快速切换** — 独立热键一键切换游戏有/无UI，执行间隙可调

信息数显、角度仪、建队宏为可选模块，关闭时不加载。

## 快速开始

### 系统要求

- Windows 10 / 11
- 游戏设置为**窗口化**或**无边框窗口**（全屏模式下叠加层无法显示）

### 运行

1. 解压后，**右键 `GunnerSight.exe` → 以管理员身份运行**
   - 管理员权限用于信息数显的 BlockInput（防止截图时鼠标干扰），非管理员也能运行但测距功能受限
2. 参考 `USER_GUIDE.md` 完成载具配置、炮镜导入和热键绑定

### 从源码运行

```bash
pip install PyQt5 mss keyboard pillow
python main.py
```

## 配置与数据

所有个人配置存于 `config/config.json`（载具、弹种、倍率、热键、各模块参数），炮镜图片存于 `resources/`。退出时自动保存，旧版本配置启动时自动迁移。

备份只需复制 `config/` 和 `resources/` 两个目录。

## 开发

- **技术栈**：Python 3 · PyQt5 · mss（截图）· keyboard（全局键盘钩子）· 自定义低级鼠标钩子 · ctypes/Win32 API
- **版本号**：唯一来源为 `gui/tabs/info_tab.py` 的 `APP_VERSION`，每次源码修改递增末位
- **打包**：PyInstaller onedir 模式，`config/` 与 `resources/` 外置在 exe 同级
