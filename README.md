# GUNNER SIGHT

Squad 屏幕准星辅助工具。透明 overlay，无侵入，不修改游戏文件。

## 功能

- **准星面板**：载具/弹种/倍率切换，自定义分划图片叠加
- **滚轮切弹种**：游戏内滚轮预选弹种，左键确认
- **角度仪**：鼠标俯仰角度测量
- **标定测距**：屏幕比例尺换算距离
- **放大镜**：屏幕中心圆形放大
- **建队宏**：自动建队循环

## 要求

- Windows 10 2004+

## 使用

1. 解压后运行 `GUNNER SIGHT.exe`
2. 在「热键」页绑定各功能热键
3. 在「载具配置」页配置车辆分划图片
4. 游戏内按热键触发功能

## 目录结构

```
GunnerSight/
├── GUNNER SIGHT.exe
├── config/
│   ├── config.json      # 用户配置
│   └── bbox_cache.json  # 分划偏移缓存（自动生成）
└── resources/           # 分划图片资源
```

## 卸载

直接删除整个文件夹。不写注册表，不留系统残留。
