# GunnerSight

Squad 载具炮手辅助工具。炮镜分划叠加、信息数显、地图比例尺测距、角度仪、建队宏，一站式实战辅助。

本地运行，不读内存，不注入，不改游戏文件。永久免费。

---

## 它能做什么

| 功能 | 一句话说明 |
|------|-----------|
| 准星叠加 | 透明置顶炮镜，按载具/弹种/倍率自动切换，缩放偏移透明度可调 |
| 信息数显 | 无UI下自动截图测距仪数值并贴回屏幕，替代原炮镜视野 |
| 标定测距 | 以游戏地图比例尺为基准标定像素比例，两点间距离实时测算 |
| 角度仪 | RawInput鼠标增量反推炮塔俯仰角，每武器站独立校准 |
| 建队宏 | 控制台建队流程自动化，循环间隔可调 |
| 全局热键 | 键盘+鼠标钩子，每功能双键槽位，支持按住触发 |

信息数显、标定测距、角度仪、建队宏均为可选模块，关闭即零消耗。

## 快速开始

**要求**：Windows 10/11，游戏设为窗口化或无边框窗口。

**运行**：右键 `GunnerSight.exe` → 以管理员身份运行（信息数显需要 BlockInput 权限）。

**五步上手**：

1. 载具配置页 → 新建载具 → 添加弹种 → 添加倍率
2. 资源库页 → 导入透明底 PNG 炮镜图片
3. 载具配置页 → 选中倍率 → 绑定对应炮镜
4. 热键设置页 → 绑定显示准星、切换倍率等热键
5. 进游戏按热键测试

详细教程见 [USER_GUIDE.md](USER_GUIDE.md)。

## 标定测距原理

以**游戏地图自带的比例尺/网格**为基准，而非任意参照物：

1. 打开游戏地图，找到已知尺寸的地图元素（如网格线间距、地图比例尺条）
2. 在屏幕上量出该已知距离占多少像素 → 得到"每像素 = 多少米"
3. 任意两点在地图上的像素距离 × 比例尺 = 实际距离

支持 33/100/300/900m 四档比例尺循环切换，组合键+测算可沿用上一次点1快速连续测距。

## 配置与数据

- 配置：`config/config.json`（载具、热键、各模块参数）
- 资源：`resources/`（炮镜图片、字体、吉祥物）
- 退出自动保存，旧版本配置启动自动迁移
- 备份 = 复制 `config/` + `resources/`

## 开发

**技术栈**：Python 3 · PyQt5 · mss · keyboard · 自定义鼠标钩子/RawInput · ctypes/Win32

**打包**：PyInstaller onedir，`config/` 与 `resources/` 外置 exe 同级
