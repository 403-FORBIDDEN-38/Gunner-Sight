## 核心特性

### 准星叠加
- 透明置顶、鼠标穿透的全屏叠加层
- 按 **载具 → 弹种 → 倍率** 三级自动切换炮镜图片
- 支持缩放、偏移、一键反色、全局/载具级透明度（二选一不叠加）

### 全局热键
- 键盘 + 鼠标全局钩子，每功能双键槽位
- 支持按下/松开触发，Hold to Aim（按住显示、松开隐藏）
- ESC 清除绑定，支持 Shift/Tab/Ctrl 单独绑定

### 多载具配置
- 每载具独立弹种、倍率、准星绑定
- 标签筛选，弹种热键按载具维度独立存储
- 载具级缩放/偏移/透明度覆盖全局设置

### 信息数显
- 无UI模式下自动恢复UI → 截图测距区域 → 恢复无UI → 叠加显示结果
- 双截取区域（测距区域 + 结果显示），替代原炮镜视野
- 执行间隙可调，适应不同硬件

### 标定测距
- 基于屏幕像素比例尺标定（33/100/300/900m 四档循环）
- 两点间游戏内距离实时测算，悬浮窗口显示结果
- 组合键切换比例尺，组合键+测算沿用上一次点1快速测距
- 可关闭零消耗，禁用后清理标定数据

### 角度仪
- 基于 RawInput 鼠标增量实时显示炮塔俯仰角
- 每载具独立校准曲线（3-11点可选），方案可切换
- 微调热键（点按小幅 / 长按连续），归零/暂离/重置
- 开火后归平可配置，随载具保存

### 建队宏
- 自动化 Squad 控制台建队流程
- 循环间隔可调，支持锁队
- 双键热键触发

### 资源库
- 炮镜图片管理，支持导入/预览
- 载具-弹种-倍率三级资源绑定

### 无UI快速切换
- 独立热键一键切换游戏有/无UI
- 执行间隙可调，最后一步UI恢复等待保留

> 信息数显、角度仪、建队宏、标定测距为可选模块，关闭时不加载、零消耗。

## 快速开始

### 系统要求

- Windows 10 / 11
- 游戏设置为**窗口化**或**无边框窗口**（全屏模式下叠加层无法显示）

### 下载运行

1. 解压后，**右键 `GunnerSight.exe` → 以管理员身份运行**
   - 管理员权限用于信息数显的 BlockInput（防止截图时鼠标干扰）
   - 非管理员也能运行，但测距/信息数显功能受限
2. 参考 [USER_GUIDE.md](USER_GUIDE.md) 完成载具配置、炮镜导入和热键绑定

### 从源码运行

```bash
pip install PyQt5 mss keyboard pillow
python main.py
```

## 配置与数据

- 所有个人配置存于 `config/config.json`（载具、弹种、倍率、热键、各模块参数）
- 炮镜图片存于 `resources/`
- 退出时自动保存，旧版本配置启动时自动迁移
- 备份只需复制 `config/` 和 `resources/` 两个目录

## 常见问题

**Q: 叠加层不显示？**
A: 确认游戏为窗口化或无边框窗口模式；确认准星显示热键已绑定并按下；检查资源库中当前载具/弹种/倍率是否有绑定的炮镜图片。

**Q: 热键不生效？**
A: 确认以管理员身份运行；检查热键是否与其他软件冲突；部分游戏独占模式下全局热键可能被拦截。

**Q: 信息数显截图黑屏？**
A: 确认游戏为无边框窗口（全屏独占模式无法截图）；适当调大执行间隙。

**Q: 角度仪数值不准？**
A: 每载具需独立校准；校准时鼠标移动速度尽量均匀；校准完成后更改角度范围需重新校准。

**Q: 关闭软件后鼠标卡顿？**
A: 已修复——确保使用最新版本，关闭时所有模块正确注销热键和RawInput设备。

## 开发

### 技术栈

- Python 3 · PyQt5
- mss（屏幕截图）
- keyboard（全局键盘钩子）
- 自定义低级鼠标钩子 + RawInput
- ctypes / Win32 API

### 架构

```
core/           逻辑层（配置管理、状态机、热键、overlay、各模块引擎）
gui/            UI层（主窗口、通用控件、热键绑定组件）
gui/tabs/       9个页签
resources/      炮镜图片、吉祥物素材
config/         用户配置（不入库）
tests/          pytest 测试套件
docs/           项目文档、审查记录、工作流
```

### 版本号

唯一来源为 `gui/tabs/info_tab.py` 的 `APP_VERSION`，每次源码修改递增末位。`version_info.txt` 同步。

### 测试

```bash
python -m pytest tests/ -v
```

### 打包

PyInstaller onedir 模式，`config/` 与 `resources/` 外置在 exe 同级：

```bash
python -m PyInstaller GunnerSight.spec --clean --noconfirm
```
